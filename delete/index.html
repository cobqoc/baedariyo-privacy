배다리요 — 데이터 삭제 요청 방법

앱 이름: 배다리요 (Google Play) · 운영: 배다리요 운영자 · 문의: baedariyo@gmail.com

배다리요는 회원가입이 없습니다. 이용자는 이름·전화번호·이메일 없이 익명 식별자로만 구분되며, 아래 방법으로 언제든 자신의 데이터를 지울 수 있습니다.

1. 앱에서 바로 삭제하기 (휴대폰 + 서버)

1. 앱 홈 화면 오른쪽 위 ⚙️(설정) 을 누릅니다.

2. 「내 자료 전부 삭제」 를 누릅니다.

3. 확인 칸에 삭제 라고 입력하고 「전부 삭제」 를 누릅니다.

  • 누르는 즉시 휴대폰의 기록과 서버의 익명 백업이 함께 지워지며, 되돌릴 수 없습니다.
  • 휴대폰이 인터넷에 연결된 상태에서 진행해 주세요. 연결이 없으면 서버 쪽 삭제가 이루어지지 않을 수 있습니다.
  • 앱을 그냥 지우면 휴대폰의 데이터만 사라지고 서버 백업은 남습니다. 서버까지 지우려면 앱을 지우기 전에 위 순서를 먼저 진행해 주세요.

2. 휴대폰이 없어 앱에서 지울 수 없을 때 — 메일로 요청

baedariyo@gmail.com 으로 「데이터 삭제 요청」이라고 보내 주세요.

회원가입이 없어 운영자는 이용자의 이름·연락처를 알지 못합니다. 휴대폰에서 미리 만든 이전 코드 나 기기 이전 파일 처럼 그 데이터의 주인임을 보여줄 수 있는 것을 함께 보내 주시면, 확인한 뒤 지체 없이 서버의 데이터를 삭제합니다. 확인할 수단이 없으면 특정 데이터를 골라 지우기 어렵습니다.

3. 삭제되는 데이터

어디삭제되는 것
휴대폰콜·정산 기록, 경비, 운행 기록(GPS 경로 포함), 장소 메모, 앱이 읽어 둔 배달앱 화면 자료
서버 (익명 계정에 연결된 것 전부)배달료·정산 기록, 배달앱 화면에서 읽은 글자, 운행 시작·종료 시각과 거리, 개인 백업(경비·정산 상세·설정·닉네임), 시간대 보너스·미션·신규배차 기록, 배달앱이 띄운 표시 시세, 가게 관측 기록

서버 데이터는 삭제를 실행하는 즉시 지워지며, 삭제한 데이터를 따로 보관하지 않습니다.

4. 삭제되지 않는 데이터와 보관 기간
